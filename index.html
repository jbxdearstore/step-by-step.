Apa Itu HTML?

HTML adalah bahasa markup yang digunakan untuk membuat struktur sebuah halaman website. Dengan HTML, kita menentukan bagian mana yang menjadi judul, paragraf, gambar, tombol, dan bagian-bagian lainnya.

Kalau website diibaratkan seperti sebuah rumah, HTML adalah kerangkanya.

  • HTML = struktur rumah (dinding, ruangan, pintu)
  • CSS = tampilan rumah (warna, gaya, dekorasi)
  • JavaScript = interaksi rumah (lampu bisa dinyalakan, pintu otomatis)

Website ini fokus mempelajari HTML terlebih dahulu, sehingga penjelasan tentang CSS dan JavaScript hanya disinggung secara singkat.

Struktur Dasar HTML

<!DOCTYPE html>
<html>
<head>
    <title>Halaman Saya</title>
</head>
<body>
    <h1>Halo Dunia!</h1>
    <p>Ini adalah halaman HTML pertama saya.</p>
</body>
</html>
<!DOCTYPE html>

Menandakan bahwa dokumen menggunakan HTML5. Ini adalah baris pertama yang wajib ada di setiap halaman HTML.

<html>

Merupakan elemen utama yang membungkus seluruh isi halaman HTML, dari awal sampai akhir.

<head>

Berisi informasi tentang halaman yang tidak langsung ditampilkan, seperti judul tab dan pengaturan lainnya.

<title>

Menentukan judul halaman yang biasanya muncul pada tab browser.

<body>

Berisi seluruh konten yang benar-benar ditampilkan kepada pengguna, seperti teks, gambar, dan tombol.

Contoh Penggunaan HTML

Beberapa contoh lengkap yang menggabungkan beberapa elemen sekaligus, supaya kamu bisa melihat bagaimana elemen-elemen tersebut bekerja bersama dalam satu halaman.

Contoh 1 — Halaman Sederhana

Halaman ini berisi judul, paragraf, tautan, dan gambar.

<!DOCTYPE html>
<html>
<head>
    <title>Halaman Sederhana</title>
</head>
<body>
    <h1>Selamat Datang</h1>
    <p>Ini adalah halaman HTML sederhana.</p>
    <a href="https://www.contoh.com">Kunjungi Contoh</a>
    <img src="gambar.jpg" alt="Contoh gambar pemandangan">
</body>
</html>
Penjelasan: Judul menggunakan <h1>, teks penjelasan menggunakan <p>, tautan menggunakan <a>, dan gambar menggunakan <img> yang dilengkapi atribut alt.

Contoh 2 — Daftar

Contoh penggunaan daftar tidak berurutan dan daftar berurutan.

<h3>Daftar Belanja</h3>
<ul>
    <li>Beras</li>
    <li>Telur</li>
    <li>Sayur</li>
</ul>

<h3>Langkah Memasak Mi Instan</h3>
<ol>
    <li>Rebus air hingga mendidih</li>
    <li>Masukkan mi ke dalam air</li>
    <li>Tunggu selama 3 menit</li>
    <li>Tiriskan dan tambahkan bumbu</li>
</ol>
Penjelasan: Gunakan <ul> saat urutan item tidak penting, seperti daftar belanja. Gunakan <ol> saat urutan penting, seperti langkah-langkah yang harus diikuti berurutan.

Contoh 3 — Tabel

Contoh tabel sederhana berisi data siswa.

<table>
    <thead>
        <tr>
            <th>No</th>
            <th>Nama</th>
            <th>Nilai</th>
        </tr>
    </thead>
    <tbody>
        <tr>
            <td>1</td>
            <td>Dina</td>
            <td>90</td>
        </tr>
        <tr>
            <td>2</td>
            <td>Budi</td>
            <td>85</td>
        </tr>
    </tbody>
</table>
Penjelasan: <table> adalah wadah utamanya, <tr> membuat satu baris, <th> digunakan untuk judul kolom, dan <td> digunakan untuk data biasa.

Contoh 4 — Formulir

Contoh formulir pendaftaran sederhana.

<form>
    <label for="nama">Nama</label>
    <input type="text" id="nama" name="nama">

    <label for="email">Email</label>
    <input type="email" id="email" name="email">

    <button type="submit">Kirim</button>
</form>

Berikut tampilan formulir tersebut:

Penjelasan: Setiap input memiliki <label> yang terhubung melalui pasangan atribut for dan id yang sama. Formulir ini hanya untuk latihan dan tidak benar-benar mengirim data ke mana pun.
